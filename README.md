# 📦 Descripción general del sistema
Este proyecto corresponde a la evaluación de la asignatura **Desarrollo Orientado a Objetos 2**. El sistema modela el funcionamiento de la empresa de logística y entregas **Speed Fast**, permitiendo gestionar la asignación de repartidores para diferentes tipos de pedidos (*Comida*, *Encomienda* y *Express*).

El desarrollo aplica los pilares fundamentales de la Programación Orientada a Objetos: **Herencia**, **Encapsulamiento**, **Polimorfismo (Sobrescritura)** y **Sobrecarga de métodos**, asegurando la validación de requisitos específicos como mochilas térmicas, límites de peso/embalaje y disponibilidad inmediata.
